# واجهة دار سامي — نسخة العرض

واجهة كاملة تعمل ببيانات وهمية. **لا تحتاج خادماً** — افتحيها من XAMPP وتصفّحي كل شيء.

---

## التشغيل

ضعي محتوى `public/` مكان القديم، ثم افتحي:

```
http://localhost/Front-Bouthaina/index.html
```

`API.MOCK = true` في `assets/js/api.js` — كل البيانات من مجلّد `mocks/`.
حين يجهز الخادم، غيّريه إلى `false` ولا شيء آخر.

---

## حساب التجربة

| | |
|---|---|
| البريد | `author@test.com` |
| كلمة السرّ | `Test12345` |
| رمز الاستعادة | `123456` |

أي كلمة سرّ أخرى **تُرفض فعلاً** — المحاكاة تفشل عمداً ليُختبر الخطأ.
الجلسة في `sessionStorage`، فتنتهي بإغلاق التبويب.

⚠️ المحاكاة كلّها داخل شرط `API.MOCK` وتختفي تماماً عند `false`.

## مسار العرض المقترح

1. **الرئيسية** — تصفّح الكتب، جرّبي البحث والتصفية.
2. **أقسام الكتب** — كل قسم يفتح الرئيسية مصفّاة عليه.
3. **أي كتاب مجاني** — «تحميل الكتاب» يُنزّل ملفاً حقيقياً.
4. **رحلة في ذاكرة الوطن** — الحالة الجديدة: **الملف مجاني والمطبوع بثمن**.
   بطاقتان: تحميل مجاني، ونسخة ورقية بـ٩٠٠ دج.
5. **تاريخ الجزائر الحديث** — ورقية فقط بـ١٢٠٠ دج. «اطلب نسخة مطبوعة»
   ← غيّري العدد: نسختان ٢٢٠٠ بدل ٢٤٠٠، وثلاث ٣١٠٠، مع سطر التوفير.
6. **السيرة النبوية للناشئين** — السعران معاً: إلكترونية ٦٠٠ وورقية ١٤٠٠.
   كل زرّ يفتح النافذة على صيغته.
7. **نشر كتاب** — «لا، هذه أول مرّة»: املئي البيانات مع كلمة سرّ.
   ثم أعيدي فتح الصفحة و«نعم، نشرت من قبل» بحساب التجربة —
   البيانات تُملأ وحدها ويظهر «حسابي» في الهيدر.
8. **حسابي** — تعديل البيانات، تغيير كلمة السرّ، عرض الكتب.
9. **المؤلفون** — البحث والترتيب الأبجدي.
10. **طباعة كتاب** — الحجم والكميات (حتى ثلاث).

---

## ما تغيّر في هذه النسخة

**حسابات المؤلفين** — بوّابة قبل النشر، حساب يُولد من الاستمارة لا من
تسجيل منفصل، دخول واستعادة كلمة سرّ برمز، وصفحة «حسابي».

**إصلاحات كانت تكسر العرض** — ١٢ كتاباً كانت تعطي «غير موجود» عند النقر،
وكل روابط صفحة الأقسام كانت ميّتة (`library.html` صفحة غير موجودة).

**تنظيف** — أثر التقييمات أُزيل نهائياً، ورقم الحساب البريدي الوهمي اختفى
مع تغيّر تدفّق الشراء، وروابط مكسورة إلى صفحات غير موجودة.

## ⚠️ للخادم — ما يجب أن يجهز

### المصادقة

الجلسة **كوكي httpOnly عبر Sanctum**، لا رمز في `localStorage`.
الواجهة لا تحمل شيئاً سرّياً؛ `credentials: "include"` في كل طلب.

```
GET  /api/auth/me
POST /api/auth/login             { email, password }
POST /api/auth/logout
POST /api/auth/password/forgot   { email }
POST /api/auth/password/verify   { email, code }
POST /api/auth/password/reset    { email, code, password }
PUT  /api/auth/profile           { name, title, phone, address, bio, extra }
POST /api/auth/password/change   { current_password, password }
```

- `POST /api/submissions` يقبل `password` للمؤلف الجديد، وينشئ الحساب
  ويفتح الجلسة، ويردّ `{ data: { user } }`.
- `authors.user_id` **قابل للإفراغ** — الطاهر وطار ومالك بن نبي لهم سجلّات
  مؤلفين بلا حسابات.
- `password/forgot` يردّ **نجاحاً دائماً** حتى لو لم يوجد البريد، وإلّا صار
  النموذج أداةً لمعرفة من له حساب.

### الكتب

**سعران مستقلّان لكل كتاب** — لا حقل `price` واحد:

| الحقل | معناه |
|---|---|
| `price_digital` | سعر الملف. **فارغ = تنزيل مجاني** |
| `price_print` | سعر النسخة المطبوعة الواحدة |
| `price_2` `price_3` `price_4` | أسعار جملة **للورقية وحدها** |
| `sale_email` | مطلوب متى وُجد أي سعر |

فيمكن أن يكون الملف مجانياً والمطبوع بثمن — وهي حال أغلب ما تنشره الدار.

`GET /api/books/{slug}` يُرجع هذه الحقول مع `files[].url` (اختياري، للروابط الموقّتة).
و`POST /api/submissions` يقبلها بالأسماء نفسها.

`POST /api/contact` بنوع `print_request`: JSON لا multipart، و`copies`
**مصفوفة** أعداد لا رقماً، و`size` من `A4` · `A5` · `16x24`.

### الأمان — الأهمّ

استمارة النشر مفتوحة، فيستطيع أي شخص رفع كتاب باسم مؤلف معروف وبريده هو.
الحواجز في الخادم لا في الواجهة:

1. الطلب يصل `pending`، والكتاب لا يظهر حتى `approved` — **شرط في
   الاستعلام** لا عادة إدارية.
2. رابط أو رمز تأكيد إلى `sale_email` قبل نشره.
3. تقييد معدّل على `/api/submissions` مع تسجيل IP.
4. تحقّق من صيغة البريد في الخادم.
